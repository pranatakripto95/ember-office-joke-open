A one-line joke about office life, written by a small deterministic program
for the make.fun bounty
[u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232](https://make.fun/competitions/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232).

`main.ts` (Node 22) writes the joke to `/output/entry.txt`:

> Our standup ran 45 minutes. Nobody stood up.

Run it with `node main.ts`. No network, no randomness — every run writes the
same 44 characters.
